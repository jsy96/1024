# 颐养通 · 比赛提交与演示说明

颐养通为居家养老服务公司提供预约、履约留痕、服务币账本与双层结算工具。公司是平台付费客户，个人和社区免费使用平台。社区签约公司、核定高龄资格并发放补贴，老人自主选择签约公司的服务员。

## 三分钟展示线索

1. **做什么**：面向社区合作的居家养老服务公司，把签约准入、老人自主选人、上门凭证和两层结算串在同一笔订单里。公司购买平台，个人和社区免费使用。
2. **为什么需要**：上门服务进入私人家庭，老人和家属需要安全、透明和长期可信。普通到店服务的好评不能替代合同准入、地址打卡、结束合影、隐私范围和人工核验。
3. **产品怎么用**：社区签约并发放高龄服务币补贴；老人跨公司自主选人预约；服务员查看电瓶车路线、天气、午餐与电量提示，当天打卡，结束后征得同意并上传合影；账本与结算逐单核对。
4. **下一步怎么长大**：普通顾客可直接预约并线下结算，不发也不扣服务币；服务员分享服务名片，让优秀的一线服务员被更多人看见；顾客可看到订单相关服务进度；AI 在后台负责路线、提醒、摘要与异常提示。
5. **商业怎么验证**：拟按公司订阅、按服务员规模分档。正式价格尚未确定，下一步用真实公司访谈和一期试用验证台账、工作量与续用意愿。

推荐依次展示封面、PPT 第 1、2、4、5、6、8、10、11、12 页，再用 Mac 视频补充实际操作。完整旁白视频可用于提交截止前复核讲稿。

## Mac / Windows 运行

**macOS**：解压 ZIP，进入 `颐养通参赛材料/产品`，双击 `启动本地.command`。如 macOS 阻止双击，在终端进入产品目录后执行：

```bash
bash 启动本地.command
```

**Windows**：解压 ZIP，进入 `颐养通参赛材料\产品`，双击 `start_windows.bat`；也可以在命令提示符中执行：

```bat
start_windows.bat
```

需要 Python 3.9+，安装时勾选 `Add Python to PATH`。Windows 脚本优先使用 `py -3`，没有时使用 `python`，并自动创建 `.venv-win` 和安装依赖。

两个平台首次启动安装依赖都需要联网；后续主业务使用本地 SQLite，无需云账号。浏览器访问 `http://127.0.0.1:8000`。端口被占用时，先停止原服务。地图、天气需联网，打卡需在浏览器中允许定位权限；无法定位时会提示，不伪造坐标。

提交包自带独立数据库 `产品/data/care-mac-demo.db`，不含当前开发机原数据库、密钥、会话、日志、虚拟环境或 Git 历史。直接克隆仓库启动时则自动建立一份空白演示库。

## 商业方案与验收

拟按公司订阅、服务员规模分档：不超过 10 名服务员建议 ¥299／月／公司，不超过 30 名建议 ¥699／月／公司，更大规模协商。**正式定价尚未确定，均为待验证建议，未实现订阅收款。** 公司平台订阅费以人民币报价；老人服务币、社区补贴、员工酬金另行核算，兑付由合同约定，不假定固定人民币比例。

可接单服务：本地安装 → 公司员工与项目初始化 → 社区合同及补贴配置 → 四端培训 → 首期账本与双层结算明细交付。

验收点：四端能登录；能跨公司选人预约；缺定位打卡或合影不能完成；消费与补贴原账可查；两层结算能生成与导出；无权用户无法读取他人的订单与照片。已通过 64 项业务与权限检查，以及四端浏览器预约、模拟定位、照片上传、结算、下载和手机布局核验。

下一步用真实公司访谈及一期试用，验证台账匹配、可节省的核账工作量、付费意愿与续用意愿。当前材料没有声称已有真实客户、收入或实测提效比例。
